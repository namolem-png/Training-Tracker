# Agent Guidelines

## Git & Version Control
- **Never stage (`git add`), commit (`git commit`), or push (`git push`) changes without explicitly asking for user confirmation first.**
- Always present the proposed changes or commit details to the user and wait for explicit approval before running any git staging, commit, or push operations.

## Engineering Principles
- Choose the simplest implementation that fully meets the current requirements.
- Fix the cause, not the symptom.
- Suggest best practices, even if they may require refactoring.
